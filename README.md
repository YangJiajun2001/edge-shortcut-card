# Edge 快捷键卡片

一个用于记录和搜索 Edge 快捷键的浏览器扩展。当前版本使用独立卡片页面，后续按设计稿改为页面内可收起/展开的悬浮卡片。

## 当前结构

- `manifest.json`：MV3 清单。
- `background.js`：窗口管理、搜索次数队列、消息处理。
- `card.html` / `card.css`：卡片页面与样式。
- `content.js`：卡片页面脚本（历史文件名，当前不再注入网页）。
- `design/`：前端设计稿与设计讨论稿。

## 加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向本目录。
4. 点工具栏图标，或按 `Alt+Shift+K`。

## 版本

- 基线：`v1.1.0`
- 设计确认：方案 A（页面内悬浮卡片，可收起为贴边胶囊）。

## 说明

- 搜索次数只由搜索框按 Enter 记录，点击条目不计数。
- 旧点击统计 `edgeShortcutStats` 不再参与排序；点“恢复”可清理。
