# Edge 快捷键卡片

页面内可收起 / 展开的 Edge 快捷键卡片。按工具栏图标或 `Alt+Shift+K` 呼出，卡片浮在当前网页右侧；收起后变成贴边胶囊。

## 形态

- **展开**：右侧悬浮卡片，可拖动；搜索、排序、列表、刷新 / 恢复。
- **收起**：贴边胶囊，点击展开；可沿右侧上下拖动。新安装默认显示收起态。
- **隐藏**：完全不在页面显示，再次按工具栏图标或 `Alt+Shift+K` 呼出。
- 展开 / 收起 / 隐藏状态、位置、排序会写入 `chrome.storage.local`，在所有标签页之间同步。
- 收起胶囊显示一条快捷键提示；**每次收起都会随机换一条**，点击展开并定位到该条。
- 从隐藏/收起用 `Alt+Shift+K` 或工具栏图标打开时，与点击胶囊一致：清空搜索、选中当前提示并滚到该条。

## 交互

- 工具栏图标 / `Alt+Shift+K`：隐藏 → 展开 → 收起 → 展开循环。
- `×`：完全隐藏；`Esc`：搜索框有字先清空，没字则收起。
- 搜索框按 `Enter`：给当前选中项 +1 搜索次数；查询为空时不计数。
- `↑↓` 选择结果，空查询时 `Home/End` 跳首尾。
- 搜索框下方显示最近 3 条按 Enter 记录过的快捷键；点击滚动高亮，不计数。
- 输入框聚焦时，顶部显示“输入框”编辑快捷键条（复制/粘贴/撤销/全选）。
- 按 **`F2`** 直接进入逐键录入（不需要点鼠标）；再按 `F2` 或 `Enter` 完成，`Esc` 取消。
- 点 `⌨` 也可进入逐键录入：逐个按 `Ctrl → Shift → T`，不要同时按；`Backspace` 删除，`Enter` 完成，`Esc` 退出。
- `+=` 和 `-` 在录入时分别显示为 `Plus` / `Minus`，不会和组合键分隔符混淆。
- F1–F12、Enter、Esc 等保留键用“特殊键”下拉或直接手输。
- `刷新`：重新读取搜索次数；`恢复`：清空搜索次数、最近记录并恢复默认排序。
- 页面内卡片依赖 content script；`edge://`、扩展商店等受限页面无法注入，这是浏览器限制。

## 键盘入口

1. 先用 `Alt+Shift+K` 展开卡片。
2. 焦点在搜索框时按 `F2`，直接进入逐键录入。
3. 如果焦点在卡片按钮上，`F2` 同样有效。
4. 录入完成后：
   - `Enter` 或 `F2`：保留当前组合并搜索；
   - `Esc`：取消本次录入。

> 不要同时按 `Ctrl+Shift+T`。Edge 会先执行浏览器快捷键，页面收不到完整的组合；逐键按是为了避开这个限制。

## 符号键：`+` / `=` / `-`

逐键录入时，符号键做了单独处理：

- `=` 或 `+` 统一记为 `Plus`；
- `-` 记为 `Minus`；
- 输入框显示 `Ctrl + Plus` / `Ctrl + Minus`；
- 结果列表和最近 3 条也显示 `Plus` / `Minus`，不会出现 `Ctrl++` 这种歧义写法；
- 匹配时按“按键集合”比较，不再把 `+` 当成分隔符，所以 `Ctrl+Plus`、`Ctrl+Minus` 能正确命中；
- “特殊键”下拉里也提供 `+ / =` 和 `- / _`，不方便按符号键时可直接选。

普通文字搜索仍支持 `ctrl+shift+t` 这种写法；符号键建议用逐键录入。

## 最近 3 条与输入框上下文

- **最近 3 条**：只在空查询时显示；来源是按 `Enter` 记录过的快捷键，去重后最多 3 条；点击会滚动并高亮对应条目，不增加计数。
- **输入框上下文**：打开卡片时如果页面焦点在 `input / textarea / contenteditable`，顶部显示“输入框”编辑快捷键条；有搜索词或正在录入时隐藏。
- **恢复**：会同时清空搜索次数、最近 3 条和排序状态。

## 发现机制：每次收起随机一条

- 收起胶囊显示 `组合键 + 短标题`，例如 `Ctrl+Shift+T / 重开标签`。
- 每次从展开态收起，都会从**全部 77 条快捷键**中随机换一条；避免和上一条重复。
- 不是每天一次；连续收起会连续换。
- 提示包括所有分类：标签页、窗口、导航、地址栏、PDF、编辑、Edge 特色等。
- 点击胶囊：展开卡片，清空当前搜索，滚动并高亮该条。
- 用 `Alt+Shift+K` / 工具栏图标从隐藏或收起打开：和点击胶囊一样，选中当前提示并定位。
- 点击提示不增加搜索次数，不加入最近 3 条。
- 新安装默认进入收起态；已有用户不强制改变当前形态。
- 不做欢迎页、不做每日 toast、不做通知、不新增权限。

> 当前用户如果之前是隐藏态，需要先展开卡片并点一次“收起”，胶囊才会出现。

## 文件

- `manifest.json`：MV3 清单。
- `background.js`：工具栏动作转发、搜索次数队列、消息处理。
- `content.js`：页面内悬浮卡片（content script，Shadow DOM；历史文件名沿用）。
- `design/`：设计稿、设计讨论稿、实现截图。
- `README.md`：本文件。

## 快捷键数据

以 [Microsoft Edge 中的键盘快捷方式](https://support.microsoft.com/zh-cn/edge/keyboard-shortcuts-in-microsoft-edge) 为准；同一动作的多个按键合并成一条，列表显示主键，副键显示在分类行。

- 当前 77 个动作（含 7 条“编辑”类上下文快捷键）。
- 支持口语/英文别名、分词 AND、子序列模糊匹配；相关性优先，频率只做并列排序。
- `Ctrl+Shift+E` 按官方页修正为“在边栏中打开搜索”；拆分屏幕不在官方页，未收录。
- `Ctrl+Shift+S` 网页捕获不在官方快捷键页，但 Microsoft 策略文档提到该快捷键，保留。
- “编辑”类是标准编辑快捷键，不属于 Edge 官方快捷键页，用于输入框上下文。
- 旧版本的点击统计 `edgeShortcutStats` 不再参与排序；“恢复”会清掉它和旧位置数据。

## 加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向本目录。
4. 点工具栏图标，或按 `Alt+Shift+K`。

## 已知限制

- 不能把真实组合键（如 `Ctrl+Shift+T`）直接录进卡片，否则会先触发 Edge 自己的快捷键；只能逐键按。
- F1–F12、Enter、Esc 等保留键无法可靠捕获，请用“特殊键”下拉或完成录入后手输。
- 不执行快捷键，只做查找、学习、记录搜索次数。
- 不做收藏、不做独立“常用”分组，频率排序就是常用顺序。
- PDF 只保留手动分类/查找，不做自动置顶。
- 仅 Windows 键位；不做 Mac、`edge://`、拼音首字母。

## 打不开时先检查

1. 在 `edge://extensions` 确认版本是 **1.6.0**，并点一次“重新加载”。
2. 在工具栏把扩展固定出来，点**工具栏图标**，不要在扩展管理页里点。
3. 在普通 `https://` 网页上测试；`edge://`、新标签页、扩展商店、PDF 查看器等受限页面无法注入，图标会短暂显示 `!`。
4. 旧标签页现在可以直接点图标补注入；如果仍无反应，刷新页面再试。
