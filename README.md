# Edge 快捷键卡片

页面内可收起 / 展开的 Edge 快捷键卡片。按工具栏图标或 `Alt+Shift+K` 呼出，卡片浮在当前网页右侧；收起后变成贴边胶囊。

## 形态

- **展开**：右侧悬浮卡片，可拖动；搜索、排序、列表、刷新 / 恢复。
- **收起**：贴边胶囊，点击展开；可沿右侧上下拖动。
- **隐藏**：完全不在页面显示，再次按工具栏图标或 `Alt+Shift+K` 呼出。
- 展开 / 收起 / 隐藏状态、位置、排序会写入 `chrome.storage.local`，在所有标签页之间同步。

## 交互

- 工具栏图标 / `Alt+Shift+K`：隐藏 → 展开 → 收起 → 展开循环。
- `×`：完全隐藏；`Esc`：搜索框有字先清空，没字则收起。
- 搜索框按 `Enter`：给当前结果第一条 +1 搜索次数；点击条目不计数。
- `刷新`：重新读取搜索次数；`恢复`：清空搜索次数并恢复默认排序。
- 页面内卡片依赖 content script；`edge://`、扩展商店等受限页面无法注入，这是浏览器限制。

## 文件

- `manifest.json`：MV3 清单。
- `background.js`：工具栏动作转发、搜索次数队列、消息处理。
- `content.js`：页面内悬浮卡片（content script，Shadow DOM；历史文件名沿用）。
- `design/`：设计稿、设计讨论稿、实现截图。
- `README.md`：本文件。

## 快捷键数据

以 [Microsoft Edge 中的键盘快捷方式](https://support.microsoft.com/zh-cn/edge/keyboard-shortcuts-in-microsoft-edge) 为准；同一动作的多个按键合并成一条，列表显示主键，副键显示在分类行。

- 当前 71 个动作。
- `Ctrl+Shift+E` 按官方页修正为“在边栏中打开搜索”；拆分屏幕不在官方页，未收录。
- `Ctrl+Shift+S` 网页捕获不在官方快捷键页，但 Microsoft 策略文档提到该快捷键，保留。
- 旧版本的点击统计 `edgeShortcutStats` 不再参与排序；“恢复”会清掉它和旧位置数据。

## 加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，指向本目录。
4. 点工具栏图标，或按 `Alt+Shift+K`。
