# Edge 快捷键卡片

一个不离开当前网页的 Edge 快捷键速查卡片。按 `Alt+Shift+K` 或工具栏图标展开，收起后变成页面右侧的胶囊，每次收起显示一条个性化快捷键提示。

> 仓库：https://github.com/YangJiajun2001/edge-shortcut-card

## 1. 初衷

这个项目面对的是一个很具体的场景：

> 想用某个功能，但不知道它有没有快捷键；
> 或者知道有快捷键，但想不起来是哪几个键。

这时通常会发生三件事：

- 去翻 Edge 官方快捷键页；
- 在搜索引擎里搜“Edge 怎么关闭标签页”；
- 干脆继续用鼠标点菜单。

前两种要离开当前页面，第三种会让快捷键永远记不住。
因此项目希望提供一个更轻的入口：**不离开页面，查一下，马上回来。**

Edge 官方快捷键页是主要数据来源。早期版本曾采用独立窗口，后来改为页面内卡片，因为它更符合“查一下就走”的使用方式。

项目真正要解决的不是“快捷键列表不够全”，而是：

> **怎么让用户在需要的那一刻，想到去查快捷键，并且真的用一次。**

## 2. 最重要的设计

### 2.1 卡片放在页面里，而不是另一个窗口

- 通过 content script 注入页面，使用 Shadow DOM 隔离样式；
- 卡片浮在当前网页右侧，不打断浏览；
- 支持展开、收起、隐藏、拖动；
- 收起后是贴边胶囊，仍然是一眼能看到的入口。

查快捷键是一个几秒钟的动作，切换窗口的代价往往比查本身还大，所以不做独立窗口。

### 2.2 收起胶囊是“发现入口”，不是装饰

这是项目最重要的设计。

- 新安装默认进入收起态；
- 胶囊显示一条快捷键：组合键 + 短标题；
- 每次从展开态收起，按个性化评分换一条；
- 点击胶囊或按 `Alt+Shift+K` 打开时，直接选中并定位到这条提示；
- 收起态按 `F8`，可以“记下已试”，不打开卡片，直接换下一条。

个性化评分会参考：

- 当前场景：输入框、代码页面、视频 / 音频、PDF；
- 搜索次数最多的分类；
- 最近 3 条所属分类；
- 还没按过“已试”的快捷键；
- 最近是否已经展示过；
- 同类目优先，随机兜底。

场景匹配会优先于一般历史偏好。例如焦点在输入框时，优先推荐复制、粘贴、撤销；在代码页面时优先开发者工具；在视频页面时优先静音 / 朗读。

因此它不是“随机推荐”，而是尽量做到：**和用户当前在做什么、最近在查什么有关。**

`F8` 是自我确认，不是自动检测真实按键。浏览器快捷键由 Edge 自己处理，扩展无法可靠拿到，所以这里不做“假检测”。

### 2.3 键盘优先，但不假装能执行

支持：

- `Alt+Shift+K`：展开 / 收起；
- `F2`：进入逐键录入；
- `↑↓`：选择结果；
- `Enter`：记录当前选中项的搜索次数；
- `F8`：收起态记下“已试”；
- `Alt+O`：打开当前选中项的 Microsoft 官方说明；
- `Esc`：清空 / 收起。

逐键录入是逐个按 `Ctrl → Shift → T`，不是同时按组合键。
因为同时按组合键会先触发 Edge 自己的快捷键，页面拿不到。`+ / =` 会显示为 `Plus`，`- / _` 显示为 `Minus`，避免和组合键分隔符混淆。

这个插件**只查不执行**。没有一键触发快捷键，也不申请 `tabs`、`sessions` 之类的权限。

### 2.4 数据以官方页为准，编辑类单独标注

- 当前 77 条动作，11 个分类；
- 主体来自 [Microsoft Edge 官方快捷键页](https://support.microsoft.com/zh-cn/edge/keyboard-shortcuts-in-microsoft-edge)；
- 同一动作的多个按键合并为一条；
- “编辑”类是标准复制 / 粘贴 / 撤销等快捷键，不属于 Edge 官方快捷键页，单独标注；
- 选中条目右侧提供“官方”链接，点击或按 `Alt+O` 在新标签页打开 Microsoft 官方页，并用文本片段尝试定位到该快捷键；
- “编辑”类不提供官方链接，按 `Alt+O` 会提示“编辑类没有官方说明”；
- 搜索支持别名、分词、子序列和组合键归一化；
- 搜索次数只统计用户按 `Enter` 记录的行为，点击条目不计数。

### 2.5 明确不做的事

- 不做收藏；
- 不做独立“常用”分组，频率排序就是常用顺序；
- 不做每日通知 / toast；
- 不自动展开卡片；
- 不执行快捷键；
- 不做 Mac；
- 不处理 `edge://`；
- 不做拼音首字母；
- 不做动作之后的 just-in-time 提示。

这些不是“以后一定做”，而是为了保持轻量主动砍掉的。

## 3. 技术选型与实现

### 选型

| 选择 | 原因 |
|---|---|
| Manifest V3 | Edge 当前扩展规范 |
| content script + Shadow DOM | 卡片注入页面，样式不被网页污染 |
| action + background service worker | 工具栏入口、消息转发、旧页面补注入 |
| 原生 JavaScript / CSS | 体量小，无构建步骤，改完刷新即可 |
| `chrome.storage.local` | 保存搜索次数、最近、状态、位置、提示历史；无后端 |
| 无网络请求 | 数据全部本地，不需要服务端 |

权限只保留：

```json
["storage", "scripting", "activeTab"]
```

content script 运行在 `<all_urls>`，不读取页面内容，只负责渲染卡片和接收搜索事件。

### 实现

核心文件：

```text
manifest.json       MV3 清单
background.js       工具栏动作、搜索次数队列、消息处理
content.js          页面内卡片、搜索、键盘、提示逻辑
icons/              工具栏图标
design/             设计稿和说明
README.md           本文件
```

几个关键实现：

- **页面内卡片**：Shadow DOM + `all: initial`，避免网页 CSS 影响；
- **旧标签页补注入**：点图标时如果 content script 不存在，用 `chrome.scripting.executeScript` 注入后重试；
- **搜索计数**：所有写入走 background 的同一条队列，避免多标签页覆盖；
- **组合键匹配**：录入时按“按键集合”比较，不把 `+` 当普通文本分隔符；
- **提示持久化**：`edgeShortcutTipIndex`、`edgeShortcutTipConfirmed`、`edgeShortcutTipHistory`；
- **键盘边界**：`F8` 只在收起态、页面有焦点、焦点不在输入框时生效；
- **测试**：`node --check` + 无头 Edge 合成键盘 / 鼠标事件验证交互。

### 运行

1. 打开 `edge://extensions`；
2. 开启“开发人员模式”；
3. 选择“加载解压缩的扩展”，指向本目录；
4. 按 `Alt+Shift+K` 或点工具栏图标。

没有构建步骤。修改 `content.js` 后，在扩展页点一次“重新加载”，再刷新网页即可。

### 已知边界

- `edge://`、扩展商店、Edge 内置 PDF 查看器等页面无法注入 content script；
- 浏览器级快捷键无法被扩展可靠捕获；
- `F8` 不是全局快捷键，只在页面有焦点时有效，输入框内不抢键；
- 仅 Windows 键位；
- PDF 只保留手动分类，不做自动置顶；
- 官方页链接通过文本片段尝试定位，页面结构变化时可能只打开到页面顶部；
- 不做真实按键使用检测，`F8` 是自我确认。
