# 设计 v2 · 轻量查找与学习

> 状态：**已确认并实现于 v1.3.0**。图：`design/card-design-v2.png` / `design/card-design-v2.svg`。

## 已确认范围

- Windows 专用。
- 主要用途：查 + 学；轻量查找。
- 不做一键执行，不新增 `tabs` / `sessions` 等权限。
- 不做收藏。
- 不做独立的“常用”分组；保留原来的频率排序（自然排在最前的 3 条就是常用）。
- 不做 Mac 适配、`edge://` 兜底、拼音首字母。
- PDF 不做自动置顶，仅保留手动分类/查找。

## 三个界面状态

### ① 默认展开（空查询）

- 搜索框下方：**最近 3 条**，显示最近按 Enter 记录过的快捷键。
- 如果打开卡片时页面焦点在 `input / textarea / contenteditable`：
  - 顶部显示一行“输入框”编辑快捷键：`Ctrl+C`、`Ctrl+V`、`Ctrl+X`、`Ctrl+Z`、`Ctrl+A` 等；
  - 不显示我们自己的搜索框。
- 下面是原有频率列表；没有额外的“常用/收藏”分组。
- 选中行有焦点框。

### ② 按键录入（逐键）

- 点搜索框旁的 `⌨` 进入。
- 每按一个键，填入一个键名：`Ctrl` → `Shift` → `T`。
- 输入框展示 `Ctrl + Shift + T`，结果实时匹配。
- `Backspace` 删除上一个键；`Enter` 完成并搜索；`Esc` 退出。
- 可捕获：`Ctrl / Shift / Alt`、字母数字、方向键、`Home / End / PgUp / PgDn / Tab / Space`、常用标点。
- **不能可靠捕获**：`F1–F12`、`Enter`、`Esc`、`Ctrl+T / Ctrl+W` 等浏览器保留键或组合；用“特殊键”下拉或直接手输。
- 输入框只填**键名**，动作名显示在结果列表。

### ③ 模糊搜索

- 支持分词 AND：`关闭 标签` 能同时匹配“关闭”“标签”。
- 支持别名：`关掉页面`、`undo close`、`devtools` 等。
- 支持子序列兜底。
- 排序：完全匹配 > 标题 > 别名 > 按键 > 分类 > 子序列；频率只做并列排序。
- 有搜索词时隐藏“最近/输入框上下文”条，只显示结果。
- 不做拼音首字母。

## 键盘操作

- 打开卡片后焦点在搜索框。
- `↓` 进入列表；`↑/↓` 移动选中项；空查询时 `Home / End` 跳首尾（有查询时保留输入框光标移动）。
- `Enter`：记录**当前选中项**的搜索次数；查询为空时不计数。
- `Esc`：有搜索词先清空，没词则收起。
- 选中项自动滚入视口，有焦点框。
- 不做执行。

## 最近 3 条

- 数据：最近 3 个按 Enter 记录过的快捷键 ID（去重）。
- 位置：搜索框下方，仅在查询为空时显示。
- 展示：键位组合胶囊；悬停显示标题。
- 点击：滚动并短暂高亮对应条目，不计数、不改变搜索。
- 刷新/重开页面后仍保留（`chrome.storage.local`）。

## 输入框上下文

- 打开卡片时检测页面当前焦点元素。
- 如果是输入框/文本域/contenteditable，顶部显示“输入框”快捷条。
- 新增一组“编辑”类数据：`Ctrl+C` 复制、`Ctrl+V` 粘贴、`Ctrl+X` 剪切、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+A` 全选、`Ctrl+Shift+V` 纯文本粘贴等。
- 如果打开时焦点不在输入框，不显示这一条。
- 不在我们自己的搜索框上触发。

## 数据调整

- 给现有 71 条加 `aliases`（每条 2–4 个口语/英文别名）。
- 新增“编辑”分类（约 7 条）。
- 现有按键结构保持合并后的形式：`keys: [['Ctrl','L'], ['Alt','D'], ['F4']]`。
- 不新增外部依赖，不做拼音库。

## 实现顺序（确认后）

1. 模糊搜索 + 别名 + 组合键归一化 + 相关性排序。
2. 键盘选中 + Enter 记录选中项 + 最近 3 条。
3. 按键录入（逐键 + 特殊键下拉）。
4. 输入框上下文编辑条。

## 验收点

- 空查询：最近 3 条出现；输入框聚焦时出现编辑条；频率列表保持原样。
- 输入 `关闭 标签`：两条相关结果排在前面；最近/上下文条隐藏。
- 按 `↓` 选择，`Enter` 记录的是选中项；空查询 Enter 不计数。
- 点 `⌨` 逐个按 `Ctrl / Shift / T`，输入框变成 `Ctrl+Shift+T`，结果匹配；`Backspace` 可删。
- F5/F12/Enter/Esc 不能直接录入，走特殊键/手输。
- 最近 3 条点击滚动高亮，不计数。
- 无收藏、无常用分组、无执行、无 Mac/edge:///拼音。

## v1.4.0 补充

- 展开后按 `F2` 直接进入/完成逐键录入，不再必须点击 `⌨`。
- `+ / =` 统一记为 `Plus`，`- / _` 记为 `Minus`；输入框、结果和最近条目都显示清晰符号名。
- 逐键查询按按键集合匹配，`+` 不再被当作分隔符。
