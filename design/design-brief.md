## 1. 形态选择：A 还是 B

你这次说“不要单独开窗口，保持停留在浏览器页面”，我理解为不再使用独立 popup 窗口。
但“停留在浏览器页面”有两种实现，取舍不同：

### 方案 A · 页面内悬浮卡片（设计图左侧，推荐）

- 用 content script + Shadow DOM 浮在当前网页上，不占独立窗口。
- 展开态：右侧悬浮卡片，可拖动；搜索、排序、列表、刷新/恢复。
- 收起态：贴边小胶囊（约 126×40），点击展开；可沿边缘拖动。
- 状态（展开/收起/隐藏）、位置、排序可写入 `chrome.storage.local`，每个标签页加载时读取，看起来像“跨标签页存在”。
- 限制：换页/刷新会重建卡片；`edge://`、扩展商店等页面无法注入悬浮层。
- 最接近原始“扎在页面”的感觉，也最适合“收起/展开”。

### 方案 B · Edge 侧边栏

- 用 `chrome.sidePanel` 做浏览器级侧边栏，切标签页不消失，`edge://` 也能用。
- 但它不能浮在网页上，宽度受浏览器控制；“收起”只能做窄条或关闭侧边栏，不如 A 自然。
- 如果你更看重“跨标签页、任何页面都在”，B 更合适；如果更看重“浮在页面、随时收起”，选 A。

**我的建议：A。** 你这次明确说“不要单独开窗口、保持停留在浏览器页面”，A 更贴近；跨标签页通过全局状态同步折中实现。

## 2. 方案 A 的交互细节（待确认）

### 2.1 三种状态

1. **展开**：完整卡片，宽约 360px，右侧悬浮，最大高度约 70vh。
2. **收起**：贴边胶囊，显示键盘图标/“快捷键”，点击展开。
3. **隐藏**：完全收起，不在页面显示；通过工具栏图标或 `Alt+Shift+K` 重新呼出。

### 2.2 按钮与快捷键

- 工具栏图标 / `Alt+Shift+K`：
  - 隐藏 → 展开
  - 展开 → 收起
  - 收起 → 展开
  - 这样同一个快捷键就能完成“展开/收起”；`×` 才是完全隐藏。
- 卡片头部：拖动区、搜索框、排序按钮、收起按钮 `−`、隐藏按钮 `×`。
- 搜索框 `Enter`：给当前第一条结果 +1 搜索次数（沿用上一轮规则）。
- `Esc`：搜索框有字时先清空；没字时收起（不是隐藏）。
- 点击条目不计数；点击列表把焦点还给搜索框。

### 2.3 跨标签页状态

- `cardState`: `expanded | collapsed | hidden`
- 每个标签页的 content script 读取同一份状态：
  - `expanded` / `collapsed`：自动显示对应形态；
  - `hidden`：不显示，直到再次呼出。
- 位置和排序也全局保存。
- 这样切换标签页时看起来像“卡片一直在”；但每个页面仍是独立渲染的实例。
- `edge://` 页面无法注入，这是浏览器限制。

### 2.4 数据模型：合并重复动作

官方列表里同一个动作常有多个快捷键（例如聚焦地址栏 `Ctrl+L` / `Alt+D` / `F4`）。如果拆成多条，会出现重复条目，搜索次数也会被拆散。

建议改成：

```js
{
  id: 'url-focus',
  title: '聚焦地址栏',
  cat: '地址栏',
  keys: [
    ['Ctrl', 'L'],
    ['Alt', 'D'],
    ['F4']
  ]
}
```

- 列表显示主键（第一组），备选键用小字或“或”展示。
- 搜索匹配所有键。
- 计数按“动作”算，不按单个键组合算。
- 设计图里“聚焦地址栏”一行就是这种形态。

## 4. 版本控制计划

建议用 Git：

```text
git init
git add .
git commit -m "chore: baseline v1.1.0"
git tag v1.1.0
```

再补：

- `.gitignore`（Thumbs.db、.DS_Store、*.log 等）
- `README.md`（结构、加载方式、设计/数据说明）
- 后续每次改动一次 commit，例如：
  - `feat: floating collapsible card`
  - `data: sync Edge shortcuts with Microsoft list`
  - `feat: search count + refresh/restore`

**当前阻塞**：命令行工具一启动就被 `D:\edge-shortcut-card` 的 Windows 权限拦住，无法执行 `git`。需要你选一种：

1. **临时切到完全权限**，我执行 `git init` / `add` / `commit` / `tag`；
2. **允许我运行一次目录权限修复脚本**（会修改该目录及父目录的权限，不修改文件内容/所有者，并打印回滚命令）；
3. **先不用 Git**，改为 `versions/` 快照目录（不是真正的版本控制，只是备份）。
