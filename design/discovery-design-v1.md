# 发现机制设计 v1.10 · 场景化提示 + 官方说明

> 状态：**已实现于 v1.10.0**。
>
> 本文是最终行为说明；`discovery-design-v1.svg` 是最初概念稿，欢迎页、“每日一条”、固定 20 条提示均已在确认后取消。

## 要解决的问题

用户不是不知道插件，而是**不知道某个操作有快捷键**。

例如：不知道 `Ctrl+Shift+T` 可以恢复刚关闭的标签页，就不会去搜索“恢复标签页”，插件也就不会被打开。

所以这次不做“等用户来搜”，而是做**主动曝光**。

## 收起胶囊：个性化一条

新安装默认进入收起态，胶囊显示两行：

```text
┌──────────────────────────┐
│ K  Ctrl+Shift+T   F8     │
│    重开标签               │
└──────────────────────────┘
```

规则：

- 每次从展开态收起，按个性化评分从全部 77 条中选一条。
- 胶囊右侧固定显示 `F8` 小键帽，提醒可以按 F8 记下已试。
- 评分参考：
  - 当前场景：输入框、代码页面、视频/音频、PDF；
  - 搜索次数最多的分类；
  - 最近 3 条所属分类；
  - 还没点过“已试”的快捷键；
  - 最近没有展示过的快捷键；
  - 同类目优先，随机兜底。
- 场景匹配优先于一般历史偏好。例如输入框内优先编辑快捷键，代码页优先开发者工具。
- 不是每天一条；连续收起会连续换。
- 显示组合键 + 短标题；长标题截断，完整标题放 `title` 悬停提示。
- 点击：清空当前搜索，展开卡片，滚动并高亮该条。
- 点击提示不写入搜索次数，不加入最近 3 条。
- 隐藏胶囊后不再提示。
- 不做欢迎页、每日 toast、通知、自动弹卡片。

## 官方说明直达

- 选中条目右侧显示“官方”链接。
- 点击链接，或在卡片内按 `Alt+O`，在新标签页打开 Microsoft Edge 官方快捷键页。
- URL 使用 `#:~:text=` 文本片段，尝试定位到对应组合键。
- 页面结构变化或组合键文本不一致时，可能只打开到页面顶部。
- “编辑”类快捷键不属于官方页，不显示官方链接；按 `Alt+O` 会提示“编辑类没有官方说明”。
- 打开官方页不改变搜索次数、最近记录或提示进度。

## 收起态：按 F8 记下“已试”

- 收起态且页面有焦点时按 `F8`：
  - 不打开卡片；
  - 当前提示记为“已试”；
  - 胶囊立即换下一条；
  - 底部短暂显示“已记下：Ctrl+… · 换下一条”。
- 如果焦点在页面输入框/文本域里，不抢 F8。
- 这是**自我确认**，不是检测真实按键。
- 浏览器快捷键（Ctrl+W、Ctrl+Shift+T 等）扩展无法可靠捕获，所以不做“假检测”。

## 键盘打开：与点击胶囊一致

- 从 `hidden` 或 `collapsed` 按 `Alt+Shift+K` / 点工具栏图标：
  - 清空搜索；
  - 选中当前提示；
  - 展开并滚动高亮。
- 从 `expanded` 再按：收起，并换下一条个性化提示。
- 打开提示不计数；关闭也不改变搜索数据。

## 点击后：卡片定位

- 卡片保持现有布局，不新增“今日”分组。
- 空查询列表，选中提示对应的条目并滚入视野。
- 用户可以继续：
  - `↑↓` 浏览；
  - `Enter` 记录搜索次数；
  - `F2` 进入逐键录入。
- 提示本身不计入频率。

## 新安装与已有用户

- **新安装**：`chrome.runtime.onInstalled` 的 `reason === 'install'` 时把默认形态设为 `collapsed`。
- **已有用户**：
  - 不强制改变当前形态；
  - 不打开欢迎页；
  - 如果当前是隐藏态，手动点一次“收起”即可看到胶囊。
- **更新扩展**：不改变形态，不打开任何页面。

## 数据

- `edgeShortcutTipIndex`：当前提示索引。
- `edgeShortcutTipConfirmed`：用户按 F8 记下“已试”的 ID。
- `edgeShortcutTipHistory`：最近展示过的 ID，最多 20 条。
- 全部保存在 `chrome.storage.local`，无外部请求。
- “恢复”会清空已试和展示历史。

## 不做

- 欢迎页；
- 每日 toast / 通知；
- 固定 20 条白名单；
- 动作之后的 just-in-time 提示；
- 真实快捷键按键检测；
- 每个页面自动展开卡片；
- 角标数字催使用；
- 右键菜单、地址栏入口；
- 选中文字自动带入。

## 验证

- 收起态按 F8：卡片保持收起，胶囊换下一条，记录“已试”。
- 输入框聚焦时按 F8：不抢键、不变化。
- 个性化：优先同类目、未试、未展示；无数据时随机。
- 点击胶囊后，卡片选中并滚到对应条目。
- 用快捷键从隐藏/收起打开，效果与点击胶囊一致。
- 场景化：输入框优先编辑类，代码页优先开发者工具。
- `Alt+O` 打开选中条目的官方链接；编辑类提示无官方说明。
- 点击提示前后，搜索次数不变。
- `F2`、搜索、最近 3 条、输入框上下文保持可用。
