# 发现机制设计 v1.6 · 每次收起随机一条快捷键

> 状态：**已实现于 v1.6.0**。
>
> 本文是最终行为说明；`discovery-design-v1.svg` 是最初概念稿，欢迎页、“每日一条”和固定 20 条提示已在确认后取消。

## 要解决的问题

用户不是不知道插件，而是**不知道某个操作有快捷键**。

例如：不知道 `Ctrl+Shift+T` 可以恢复刚关闭的标签页，就不会去搜索“恢复标签页”，插件也就不会被打开。

所以这次不做“等用户来搜”，而是做**主动曝光**。

## 收起胶囊：每次收起随机换一条

新安装默认进入收起态，胶囊显示两行：

```text
┌──────────────────────┐
│ K  Ctrl+Shift+T   ›  │
│    重开标签           │
└──────────────────────┘
```

规则：

- 每次从展开态收起，从**全部 77 条快捷键**中随机选一条。
- 避免和上一条重复；连续收起会连续换。
- 不是每天一条；不是固定 20 条。
- 显示组合键 + 短标题；长标题截断，完整标题放 `title` 悬停提示。
- 点击：清空当前搜索，展开卡片，滚动并高亮该条。
- 点击提示不写入搜索次数，不加入最近 3 条。
- 隐藏胶囊后不再提示。
- 不做欢迎页、每日 toast、通知、自动弹卡片。

## 键盘打开：与点击胶囊一致

- 从 `hidden` 或 `collapsed` 按 `Alt+Shift+K` / 点工具栏图标：
  - 清空搜索；
  - 选中当前提示；
  - 展开并滚动高亮。
- 从 `expanded` 再按：收起，并随机换下一条提示。
- 打开提示不计数；关闭也不改变搜索数据。

## 点击后：卡片定位

- 卡片保持现有布局，不新增“今日”分组。
- 空查询列表，选中提示对应的条目并滚入视野。
- 用户可以继续：
  - `↑↓` 浏览；
  - `Enter` 记录搜索次数；
  - `F2` 进入逐键录入。
- 提示本身不计入频率。

## 新安装与已有用户

- **新安装**：`chrome.runtime.onInstalled` 的 `reason === 'install'` 时把默认形态设为 `collapsed`。
- **已有用户**：
  - 不强制改变当前形态；
  - 不打开欢迎页；
  - 如果当前是隐藏态，手动点一次“收起”即可看到胶囊。
- **更新扩展**：不改变形态，不打开任何页面。

## 数据

- `edgeShortcutTipIndex`：当前提示在全部快捷键中的索引，保存在 `chrome.storage.local`。
- 每次收起随机生成新索引，避开当前索引。
- 提示候选来自现有 77 条快捷键数据，无外部请求。

## 不做

- 欢迎页；
- 每日 toast / 通知；
- 固定 20 条白名单；
- 每个页面自动展开卡片；
- 角标数字催使用；
- 右键菜单、地址栏入口；
- 选中文字自动带入。

## 验证

- 首次收起显示一条随机提示。
- 再次收起随机换另一条，索引变化且不等于上一条。
- 点击胶囊后，卡片选中并滚到对应条目。
- 用快捷键从隐藏/收起打开，效果与点击胶囊一致。
- 点击提示前后，搜索次数不变。
- `F2`、搜索、最近 3 条、输入框上下文保持可用。
