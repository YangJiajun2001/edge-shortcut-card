# 发现机制设计 v1.5 · 每次收起一条快捷键

> 状态：**已实现于 v1.5.0**。
>
> 本文是最终行为说明；`discovery-design-v1.svg` 是最初概念稿，欢迎页与“每日一条”已在确认后取消。

## 要解决的问题

用户不是不知道插件，而是**不知道某个操作有快捷键**。

例如：不知道 `Ctrl+Shift+T` 可以恢复刚关闭的标签页，就不会去搜索“恢复标签页”，插件也就不会被打开。

所以这次不做“等用户来搜”，而是做**主动曝光**。

## 收起胶囊：每次收起换一条

新安装默认进入收起态，胶囊显示两行：

```text
┌──────────────────────┐
│ ⌨  Ctrl+Shift+T   ›  │
│    重开标签           │
└──────────────────────┘
```

规则：

- 每次从展开态收起，按顺序换到下一条提示。
- 不是每天一条；连续收起会连续换。
- 提示来自 20 条高价值、低认知快捷键。
- 显示组合键 + 短标题；完整标题放 `title` 悬停提示。
- 点击：清空当前搜索，展开卡片，滚动并高亮该条。
- 点击提示不写入搜索次数，不加入最近 3 条。
- 隐藏胶囊后不再提示。
- 不做欢迎页、每日 toast、通知、自动弹卡片。

## 点击后：卡片定位

- 卡片保持现有布局，不新增“今日”分组。
- 空查询列表，选中提示对应的条目并滚入视野。
- 用户可以继续：
  - `↑↓` 浏览；
  - `Enter` 记录搜索次数；
  - `F2` 进入逐键录入。
- 提示本身不计入频率。

## 新安装与已有用户

- **新安装**：`chrome.runtime.onInstalled` 的 `reason === 'install'` 时把默认形态设为 `collapsed`。
- **已有用户**：
  - 不强制改变当前形态；
  - 不打开欢迎页；
  - 如果当前是隐藏态，手动点一次“收起”即可看到胶囊。
- **更新扩展**：不改变形态，不打开任何页面。

## 数据

- `edgeShortcutTipIndex`：当前提示序号，保存在 `chrome.storage.local`。
- 提示候选来自现有快捷键数据，无外部请求。
- 顺序轮换，20 条全部展示后从第一条重新开始。

## 不做

- 欢迎页；
- 每日 toast / 通知；
- 每个页面自动展开卡片；
- 角标数字催使用；
- 右键菜单、地址栏入口；
- 选中文字自动带入。

## 验证

- 首次收起显示第一条 `Ctrl+Shift+T / 重开标签`。
- 再收起切到 `Ctrl+Shift+N / 隐私窗口`。
- 点击胶囊后，卡片选中并滚到对应条目。
- 点击提示前后，搜索次数不变。
- `F2`、搜索、最近 3 条、输入框上下文保持可用。
