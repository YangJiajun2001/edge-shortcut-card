# UI 方向 A · 平静工具风

> 状态：**已确认并实现于 v1.11.0**。
>
> 图：`design/ui-a-v1.png` / `design/ui-a-v1.svg`

## 目标

保持现有结构和信息密度，只做视觉收敛：

- 安静、顺手、每天看不累；
- 360px 宽度不变；
- 不新增面板或分组；
- 键帽语言统一；
- 深浅色同一套层级。

## 关键改动

### 1. F2 从图标改成键帽

- 搜索框右侧：`F2` 键帽；
- 与胶囊里的 `F8` 使用同一尺寸、圆角、描边；
- 悬停提示：`按 F2 逐键录入`。

### 2. 官方入口改为 `↗`

- 只在选中/悬停时出现；
- 位置在搜索次数左侧；
- 点击或 `Alt+O` 打开官方页；
- 无障碍标签仍为“打开 Microsoft 官方说明”；
- 不再使用文字“官方”，减少行内拥挤。

### 3. 页脚分组

- 左侧两行提示：`↑↓ 选择 · Enter 记录` / `F2 录入 · Alt+O 官方`；
- 右侧：刷新、恢复；
- 恢复保持次要视觉，不用强危险色。

### 4. 胶囊

- 保持两行：组合键 + 短标题；
- 右侧 `F8` 小键帽；
- 不加第三行；
- 点击展开，按 F8 记下已试。

### 5. 深色模式

- 只替换表面色、文字色和边框；
- 强调色保持蓝色系；
- 选中行使用浅色底 + 左侧强调，不使用发光。

## 基础参数

| 项目 | 值 |
|---|---|
| 卡片宽度 | 360px |
| 卡片圆角 | 14px |
| 行圆角 | 8px |
| 键帽圆角 | 5px |
| 主色（浅色） | `#0B7DDA` |
| 主色（深色） | `#4DA3FF` |
| 选中底（浅色） | `#E8F2FD` |
| 选中底（深色） | `#1E344D` |
| 正文 | 10.5px |
| 辅助 | 8.5px |
| 键帽 | 等宽 9px |
| 动效 | 120–160ms |

## 不做

- 不改成键帽桌面风；
- 不增加 380px 宽度；
- 不新增“收藏 / 常用”分组；
- 不把官方入口移到页脚；
- 不在展开态重复显示 F8；
- 不改搜索、提示、F8、Alt+O 的行为。

## 实现顺序（确认后）

1. 统一键帽 CSS；
2. `⌨` 改为 `F2` 键帽；
3. 官方文字改为 `↗`，保留 Alt+O；
4. 页脚和深色细节收敛；
5. 无头 Edge 截图与交互回归。
